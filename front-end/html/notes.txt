internal css
    css declared in the html page
    <style>

inline css
    it slows the down page loading
    css will be declared in the element
    <h1 style=""></h1>


css props
key:value
color:#2ed9d3


classname
    it can be added to one or more elements
    declared using dot(.)
    access using class="name" in the element
    ex:
        <h1 class="cls1"></h1>
id
    it can be added to only one element
    should be unique
    declared using hash(#)
    access using id="name" in the element
    ex:
        <h1 id="id1"></h1>

block or inline

block:
    always takes full width.
    ex: div,header,p,h1.etc
    block tags can hold other tags
inline:
    only the for the content it takes width
    ex:span,a,input.etc
    inline tags cannot hold other tags
